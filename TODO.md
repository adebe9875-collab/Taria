# Taria roadmap

## 0.3.0 — CLI foundation
- [x] Terminal-native command line; no GTK window.
- [x] APT/DPKG search, install, remove, list and updates.
- [x] Snap search, install, remove, list and refresh.
- [x] Pacman adapter for Arch-based systems.
- [x] GitHub repository search and issue lookup.
- [x] Local error log and doctor command.
- [x] GitHub release self-update with SHA-256 verification.
- [x] System integration under /usr/local/bin with man page and Bash completion.
- [ ] End-to-end build and test on Ubuntu 26.10 and Arch.

## 0.4.0 — Catalog and recovery
- [ ] Curated GitHub app manifest with publisher, architecture, release asset, checksum and install metadata.
- [ ] GitHub app installation and recorded uninstall metadata.
- [ ] Terminal progress output and JSON output mode.
- [ ] Signed releases with separately managed public verification key.
- [ ] User-reviewed diagnostic issue report workflow.

## Later
- [ ] Flatpak and AppImage integrations.
- [ ] AArch64 release workflow.
- [ ] Debian package and Ubuntu repository packaging.
- [ ] Offline package metadata cache and transaction history.
